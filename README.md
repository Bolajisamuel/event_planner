# Event Planner Landing Page

A landing page for an event planning organization, built with React function components as part of an IBM Skills Network lab.

## Sections
- Description with a call-to-action button
- Event categories (Social, Entertainment, Community)
- Features
- Testimonials
- Contact form
- Footer (separate `Footer` component)

## Tech
- React (function components, JSX)
- Vite
- CSS

## Run locally
```bash
npm install
npm run dev
```
Then open the local address shown in the terminal (usually http://localhost:5173).
